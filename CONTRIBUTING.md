# Contributing

Issues and PRs are welcome. Small, focused changes are easiest to review.

1. Fork the repo and create a branch.
2. Run `npm run dev` and make your change. No installation is needed.
3. Run `npm run check`. Add a behavior test for a physics or control regression when useful.
4. Check browser visuals or mouse capture if your change affects them.
5. Open a PR describing what changed and how you checked it.

For handling feedback, include the selected profile or exported settings, camera view, inputs and a short recording. Controlled axis pulses are much more useful than a general feeling report. A change that feels better is welcome, but footage alone does not establish exact WARDOGS physics parity.

Keep HUD and menus minimal. The aircraft stays unshaded in both looks. Preserve existing saved custom settings when changing stock handling.

Keep third-party credits and licenses with their assets. Contributions to Warbird code are under the MIT license; do not add extracted game assets or reference videos. Never include credentials, local recordings or personal calibration exports.
